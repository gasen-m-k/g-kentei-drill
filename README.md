# G検定ドリル

G検定（JDLA Deep Learning for GENERAL）対策の4択ドリル。

公開ページ: https://gasen-m-k.github.io/g-kentei-drill/

## できること

- **卒業モード**：2回続けて正解した問題は出なくなる。卒業マップと割合で進み具合が見える
- **まだ解いていない問題**／**苦手な問題**／**要対策フラグを付けた問題**／**全問ランダム**
- **模擬テスト**：本番と同じペース（100分・145問程度 → 1問約41秒）で解き、最後に答え合わせ
- 分野での絞り込み、1回の問題数（10／20／30／全部）
- 受ける回の残り日数と申込期間の表示（2027年の日程）
- 記録はこの端末に保存し、GitHubの秘密Gistで端末間を同期（設定画面でトークンを入れる）
- 一度開けば電波のない場所でも解ける

## 問題

`data/src/` に分野ごとのJSONがあり、`python3 tools/build_questions.py` で `data/questions.json` にまとめる。
公式シラバス（G2024#6〜）の10分野に沿ったオリジナル問題で、本番の過去問ではない。
問題IDは記録と結びついているので、問題を直すときもIDは変えない。

## 記録の形式

1回解くごとに `[問題ID, 時刻(ms), 正解なら1, 選んだ選択肢, モード, 端末ID]` を追記するログ。
端末間ではログを重複なく足し合わせ、要対策フラグや設定は新しいほうを採用する。
