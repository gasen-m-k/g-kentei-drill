# G検定ドリル

G検定（JDLA Deep Learning for GENERAL）対策の4択ドリル。

公開ページ: https://gasen-m-k.github.io/g-kentei-drill/

## できること

- **卒業モード**：2回続けて正解した問題は出なくなる。卒業マップと割合で進み具合が見える
- **まだ解いていない問題**／**苦手な問題**／**要対策フラグを付けた問題**／**全問ランダム**
- **模擬テスト**：本番と同じペース（100分・145問程度 → 1問約41秒）で解き、最後に答え合わせ
- 分野での絞り込み、1回の問題数（10／20／30／全部）
- 受ける回の残り日数と申込期間の表示（2027年の日程）
- 記録はこの端末に保存し、GitHubの秘密Gistで端末間を同期（設定画面でトークンを入れる）
- 一度開けば電波のない場所でも解ける
- **印刷用カンペの仕分け**：問題ごとに「印刷用に入れる／入れない」とメモを付けられる。未判断の問題はおすすめ（`k`）に従う。「印刷用カンペ」画面から、Claudeに渡す材料を書き出せる
- **問題の取り込み**：本の問題など、公開できない問題をファイルで読み込める。この端末と秘密Gistだけに保存し、端末間で同期する

## 問題

`data/src/` に分野ごとのJSONがあり、`python3 tools/build_questions.py` で `data/questions.json` にまとめる。
公式シラバス（G2024#6〜）の10分野に沿ったオリジナル問題で、本番の過去問ではない。
問題IDは記録と結びついているので、問題を直すときもIDは変えない。
`k` は印刷用カンペのおすすめ（1＝入れる）。元データに書けばそれを使い、なければビルド時に目安で決める。

## 取り込む問題のファイル

公開リポジトリには入れない。アプリの「設定と同期 → 問題ファイルを読み込む」から読み込む。

```json
{"app":"g-kentei-drill-pack","v":1,"updated":0,"q":[
  {"id":"bk-03-012","cat":"c03","s":"小見出し","q":"問題文","c":["選択肢1","選択肢2","選択肢3","選択肢4"],"a":0,"e":"解説","k":1,"src":"本"}
]}
```

- `cat` はアプリの10分野（c01〜c10）、`a` は正解の番号（0から）、選択肢は2〜6個
- 同じ `id` の問題は新しいファイルの内容で上書きされる

## 記録の形式

1回解くごとに `[問題ID, 時刻(ms), 正解なら1, 選んだ選択肢, モード, 端末ID]` を追記するログ。
端末間ではログを重複なく足し合わせ、要対策フラグ・印刷用の仕分け・メモ・設定は新しいほうを採用する。
取り込んだ問題は同じGistの `g-kentei-drill-book.json` に置き、更新時刻が新しいほうを採用する。
